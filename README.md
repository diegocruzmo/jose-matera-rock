# José Matera — Rock

Landing page creada con React + Vite.

## Ejecutar

```bash
npm install
npm run dev
```

## Personalización rápida

- `src/data/events.js`: próximos eventos.
- `src/data/releases.js`: IDs de YouTube.
- `src/data/media.js`: videos musicales y episodios del podcast de la página `/videos`.
- `src/data/lyrics.js`: canciones/letras.
- `src/data/socials.js`: redes sociales.
- `public/images/events/`: flyers reales.
- `public/images/hero/jose-matera.png`: imagen principal.
